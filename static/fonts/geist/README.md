# Geist font asset

Unmodified Latin variable font from `@fontsource-variable/geist` 5.3.0, reused from the previous editor's installed package. Only normal weights 100–900 for the Latin subset are included; other characters use the system fallback.

- Upstream: https://github.com/vercel/geist-font
- Distribution: https://github.com/fontsource/font-files/tree/main/fonts/variable/geist
