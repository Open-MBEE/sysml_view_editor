# ABeeZee font asset

Unmodified Latin subset of ABeeZee Regular from `@fontsource/abeezee` 5.3.0. ABeeZee Regular is the typeface named by the [OpenMBEE brand guidelines](https://www.openmbee.org/brand.html). Only the regular weight for the Latin subset is included; heavier weights are synthesized by the browser and other characters use the system fallback.

- Upstream: https://github.com/googlefonts/abeezee
- Distribution: https://github.com/fontsource/font-files/tree/main/fonts/google/abeezee
